## v2.0 အသစ်ပါဝင်မှုများ
- 📄 **စာရင်းပုံစံ (list)** — တကြောင်းချင်း ရှင်းရှင်းလေး
- 👆 ထိလိုက်ရင် **modal** ပွင့် — စာမျက်နှာတခုလုံး blur + မှိန်, ရွှေရောင်ကတ် highlight
- 💬 ရှင်းလင်းချက် **မြန်မာလို အတိုချုပ်** — ကတ်ထဲမှာပဲ ပြ
- 🔘 icon သီးသန့် 28px — ဘယ်ဘက် 📋 ကူးယူ, ညာဘက် 🤍 အကြိုက်ဆုံး
- 🧹 Toolbar ၂ တန်းပါးပါးလေး + အောက်ဆွဲချရင် **ပုန်းသွား**မယ်
- 📂 Category filter — 🔍 ဘေးက 📂 icon နှိပ်မှ ပွင့်
- ⭐ အကြိုက်ဆုံး သိမ်းဆည်းမှု (ဖုန်း/browser ထဲမှာ)
- 🌙 **Day / Night / System** — ခေါင်းစဉ်ညာဘက်က icon နှိပ်ပြီး ပြောင်း
- 🖼️ Logo header မှာ ပါတယ်

## ပါဝင်တဲ့ဖိုင်များ
- `index.html` — app တစ်ခုလုံး (logo + favicon အပါ, API key မလို)
